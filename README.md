Описание проекта:

    Primitive DB — это учебный проект, представляющий собой примитивную базу данных, работающую через командную строку. Программа позволяет создавать и удалять таблицы, а также выполнять полный набор CRUD-операций (создание, чтение, обновление и удаление записей). 
    
    Данные сохраняются на диск в формате JSON:
    Структура таблиц - метаданные сохраняются в файле db_meta.json;
    Сами даные - в файлах в папке data/. 
    
    В проекте реализованы  следующие декораторы:
    1. Для обработки ошибок;
    2. Для подтверждения опасных действий;
    3. Для замера времени выполнения функции;
    4. Для кэширования результатов запросов.

Инструкция по установке и запуску:

    Для работы с проектом необходим инструмент uv.
    
    1. Откройте терминал на своем компьютере (в той папке, куда хотите скачать проект).

    2. Склонируйте репозиторий в эту папку, введя команду в терминале:
    git clone https://github.com/rozzza-muhamedova/project-2_Muhamedova_M26-555.git

    3. Перейдите в папку проекта.

    4. Соберите пакет и установите его глобально:

    uv build
    uv tool install dist/*.whl --force


Функции:

    create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу с именем и колонками
    Пример использования:
    >>>Введите команду: create_table users name:str age:int is_active:bool
    Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

    list_tables - показать список всех таблиц
    Пример использования:
    >>>Введите команду: list_tables
    - users

    drop_table <имя_таблицы> - удалить таблицу
    Пример использования:
    >>>Введите команду: drop_table users
    Таблица "users" успешно удалена.

    insert into <имя_таблицы> values (<значение1>, <значение2>, ...) - создать запись
    Пример использования:
    >>> Введите команду: insert into users values ("Sergei", 28, true)
    Запись с ID=1 успешно добавлена в таблицу "users".

    select from <имя_таблицы> where <столбец> = <значение> - прочитать записи по условию
    Пример использования:
    >>> Введите команду: select from users where age = 28
    +----+--------+-----+-----------+
    | ID |  name  | age | is_active |
    +----+--------+-----+-----------+
    | 1  | Sergei | 28  |    True   |
    +----+--------+-----+-----------+

    update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия> - обновить запись
    Пример использования:
    >>> Введите команду: update users set age = 29 where name = "Sergei"
    Запись с ID=1 в таблице "users" успешно обновлена.


    delete from <имя_таблицы> where <столбец> = <значение> - удалить запись
    Пример использования:
    >>> Введите команду: delete from users where ID = 1
    Запись с ID=1 успешно удалена из таблицы "users".


    info <имя_таблицы> - вывести информацию о таблице
    Пример использования:
    >>> Введите команду: info users
    Таблица: users
    Столбцы: ID:int, name:str, age:int, is_active:bool
    Количество записей: 0

    
Общие команды:

    help - справочная информация
    Пример использования:
    >>>Введите команду: help

    >>>Введите команду: help

    ***Процесс работы с таблицей***
    Функции:
    <command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
    <command> list_tables - показать список всех таблиц
    <command> drop_table <имя_таблицы> - удалить таблицу

    ***Операции с данными***
    Функции:
    <command> insert into <имя_таблицы> values (<значение1>, <значение2>, ...) - создать запись
    <command> select from <имя_таблицы> where <столбец> = <значение> - прочитать записи по условию
    <command> select from <имя_таблицы> - прочитать все записи
    <command> update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия> - обновить запись
    <command> delete from <имя_таблицы> where <столбец> = <значение> - удалить запись
    <command> info <имя_таблицы> - вывести информацию о таблице

    Общие команды:
    <command> exit - выход из программы
    <command> help - справочная информация



Декораторы:

    handle_db_errors - перехватывает KeyError (например, обращение к несуществующей таблице), ValueError (ошибки валидации типов) и FileNotFoundError

    confirm_action("удаление таблицы"/"удаление записи") - запрашивает у пользователя подтверждение для опасных операций, таких как: drop_table, delete

    log_time - замеряет время выполнения функции и выводит его в консоль. Применен к "медленным" операциям, которые работают с файлами: select и insert.

    create_cacher() - функция с замыканием для кэширования. Возвращает внутреннюю функцию cache_result(key, value_func). Интегрирована в операцию select, чтобы кэшировать результаты одинаковых запросов.
